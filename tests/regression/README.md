# Regression Tests

Регрессионные тесты для dap_tpl - тесты, которые проверяют исправление конкретных багов и предотвращают их повторное появление.

## Назначение

Регрессионные тесты создаются для:
- Проверки исправления конкретных багов
- Предотвращения регрессий (повторного появления исправленных багов)
- Документирования известных проблем и их решений

## Структура

Каждый регрессионный тест должен:
- Содержать описание бага в комментариях
- Указывать файл, где был исправлен баг
- Проверять как минимум один сценарий, который ранее не работал
- Иметь понятное имя, отражающее суть бага

## Запуск

```bash
# Запустить все регрессионные тесты
cd dap_tpl/tests
./run.sh regression

# Запустить конкретный тест
cd dap_tpl/tests/regression
./test_for_newline_separator.sh
```

## Тесты

### test_for_newline_separator.sh

**Баг:** При использовании `{{#for entry in DATA|newline}}` фильтр `|newline` не обрабатывался правильно - сепаратор `"\n"` устанавливался, но логика разделения не обрабатывала его корректно.

**Исправлено в:** `constructs/for/evaluator.awk`

**Проверяет:**
- Базовую обработку newline-separated данных с фильтром `|newline`
- Обработку данных с pipe-separated записями внутри newline-separated списка
- Пустые данные
- Одиночную запись
- Реальный сценарий генерации function wrappers

## Добавление нового регрессионного теста

1. Создайте файл `test_<описание_бага>.sh` в этой папке
2. Добавьте описание бага в комментариях в начале файла
3. Укажите файл, где был исправлен баг
4. Напишите тесты, проверяющие исправление
5. Убедитесь, что тест проходит: `./test_<описание_бага>.sh`
6. Обновите этот README, добавив описание нового теста
